Executive finding

Paper-style random split reproduces strong headline numbers. Validation accuracy reached 94.70% for words and 99.20% for phrases, above Utama et al.'s reported 92.28%/97.57% validation values and 93.03%/95.18% test values.

Speaker grouping changes the conclusion. With no speaker overlap, words fell to 50.65% and phrases to 25.00%. The phrase result equals four-class chance accuracy; macro F1 of 0.10 confirms severe class collapse, not useful unseen-speaker performance.

Random and grouped numbers answer different questions. Do not present the random result as speaker-independent generalization.

Replication configuration

  • IndoLR: 5,807 videos, 8 speakers
  • Words: 4,153 videos, 10 classes
  • Phrases: 1,654 videos, 4 classes
  • 40 lip landmarks × x/y = 80 features
  • Words: 40 frames; phrases: 60 frames
  • Per-frame mouth-box min/max normalization
  • Two-layer bidirectional LSTM + attention
  • Adam, learning rate 0.005, weight decay 1e-5
  • Batch size 32, dropout 0.5, 100 epochs

Model validation

  • Word model: 175,499 trainable parameters
  • Phrase model: 2,271,749 trainable parameters
  • Counts match Utama et al. Table 2 exactly
  • Best checkpoint selected by validation accuracy
  • No augmentation or class weighting
  • No test set in this reproduction

All four checkpoints and JSON/CSV logs remain on the GPU PC under output/checkpoints/ and output/logs/.
