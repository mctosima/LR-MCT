MCT-LR design

Fusion architecture combining grayscale mouth ROI (80×80) and 40-point lip landmarks via bidirectional cross-attention, followed by a 2-layer BiGRU temporal backend with attention pooling. ~4.15M parameters — larger than both Utama (175K–2.27M) and Aripin (1.68M).

Architecture draws from LipFormer (IEEE TCSVT 2023) and Cross-Attention Fusion (Daou et al. 2024). 3D conv frontend → 3-stage ResNet → 2-layer transformer on landmarks → bidirectional cross-attention → BiGRU + attention → FC.

Results pending full GPU training. Run via bash src/training/run_all_mct_lr.sh.

Executive finding

Image beats landmark on both random and unseen-speaker evaluation. Aripin's LRCN-3Conv reaches 98.88% random words and 99.20% random phrases — exceeding both Utama's and Aripin's own reported test numbers. The gap widens on speaker-grouped evaluation: LRCN-3Conv achieves 59.52% on phrases vs. Utama's 25.00%, confirming ROI images capture speaker-invariant visual cues that landmark coordinates miss.

Random and grouped numbers answer different questions. Do not present random results as speaker-independent generalization.

Replication configuration

  • IndoLR: 5,807 videos, 8 speakers
  • Words: 4,153 videos, 10 classes
  • Phrases: 1,654 videos, 4 classes
  • 40 lip landmarks × x/y = 80 features
  • Words: 40 frames; phrases: 60 frames
  • Per-frame mouth-box min/max normalization
  • Two-layer bidirectional LSTM + attention
  • Adam, learning rate 0.005, weight decay 1e-5
  • Batch size 32, dropout 0.5, 100 epochs

Model validation

  • Word model: 175,499 trainable parameters
  • Phrase model: 2,271,749 trainable parameters
  • Counts match Utama et al. Table 2 exactly
  • Best checkpoint selected by validation accuracy
  • No augmentation or class weighting
  • No test set in this reproduction

All four checkpoints and JSON/CSV logs remain on the GPU PC under output/checkpoints/ and output/logs/.
