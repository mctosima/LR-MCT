MCT-LR design

Late-fusion architecture combines Aripin's 3-convolution-block image backbone with Utama's 2-layer BiLSTM landmark backbone. Each stream extracts features independently. Concatenated features (64 + 128 = 192) pass through shallow fusion head (Linear → ReLU → Dropout → Linear). Total size: ~1.88M parameters.

Architecture draws from LipFormer (IEEE TCSVT 2023) and Cross-Attention Fusion (Daou et al. 2024), simplified to late fusion after cross-attention bottlenecks proved unstable at batch size 4.

Late fusion keeps both backbones independent until feature alignment. Image features contribute 64 dimensions; attention-pooled landmark features contribute 128 dimensions; shallow MLP produces class logits.

Image backbone

  • Three convolution stages with batch normalization, ReLU, max pooling, and dropout.
  • Flattened frame features feed one-layer LSTM.
  • Last hidden state becomes 64-dimensional image representation.

Landmark backbone

  • Normalized 40-point lip sequence enters two-layer bidirectional LSTM.
  • Attention scores weight temporal features through softmax.
  • Weighted sum becomes 128-dimensional landmark representation.

Design reading

Late fusion offers clean modality separation, not guaranteed complementarity. In these experiments, image-only model leads on random and grouped validation. MCT-LR reaches 95.35% random-word accuracy but falls to 11.06% grouped-word accuracy. Stronger cross-attention or contrastive fusion remains open work.
