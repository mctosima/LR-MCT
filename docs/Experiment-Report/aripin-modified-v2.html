AripinModifiedV2 design

Original Aripin appearance path + signed motion channel + padded-by-example masking. V2 retains the proven three-block 1→16→32→64 spatial encoder that produces a full 64×10×10 mouth-layout descriptor per frame. It adds an in-model signed-difference motion stream: consecutive frame deltas are split into positive and negative channels (2-channel input) then encoded through a compact 2→8→16→32 spatial backbone. Both streams feed independent 64-unit single-layer LSTMs whose outputs fuse through a zero-initialized residual gate—motion evidence is gated in only when training proves it useful. Tail padding (from center-crop preprocessing) is masked via pack_padded_sequence, last-valid endpoint selection, and masked additive attention pooling.

Reference: Petridis et al., End-to-End Visual Speech Recognition for Small-Scale Datasets (PRL 2019, arXiv:1904.01954) for raw/difference stream complementarity on small datasets.

Both streams encode valid frames only via pack_padded_sequence. The last-valid timestep and masked attention scores both exclude padded tails, so black frames never contribute to the classifier input.

Raw backbone

  • Three 3×3 Conv blocks: 1→16, 16→32, 32→64
  • Each block: Conv2d → ReLU → MaxPool2d(2) → Dropout(0.25)
  • Preserves complete 64×10×10 mouth map
  • Flatten → 6,400-d per-frame descriptor
  • LSTM(6400, 64, 1 layer, batch_first)
  • Identical to LRCN3Conv spatial path

Motion backbone

  • Consecutive signed frame differences in-model
  • Split: max(Δ,0) and max(−Δ,0) as 2 channels
  • Compact encoder: 2→8→16→32 (half widths of raw)
  • Same block pattern: Conv2d → ReLU → MaxPool2d(2) → Dropout(0.25)
  • Flatten → 3,200-d; LSTM(3200, 64, 1 layer)
  • Opening/closing direction distinguishable via split

Regularisation

  • Dropout 0.25 (spatial blocks), 0.5 (LSTM output, classifier)
  • Zero-initialized motion gate (bias −2)
  • Contrast ±15%, brightness ±8%, Gaussian noise σ=0.015
  • Per-utterance time-consistent affine jitter (scale 0.95–1.05, translate ±5%)
  • Gradient clipping at 5.0
  • Padding preserved through all augmentation

Training configuration

  • Optimizer: Adam, lr=5e-4, wd=1e-5 (original Aripin)
  • Batch size 4, no gradient accumulation
  • Max 100 epochs, no early stopping
  • Best checkpoint by validation accuracy (loss tie-breaker)
  • No label smoothing, no LR schedule
  • Mixed precision (AMP) on CUDA
  • CrossEntropyLoss, no auxiliary loss

Design rationale

Original Aripin's spatial backbone is the strongest known inductive bias for this dataset. The three 3×3 conv blocks preserve a full 10×10 mouth map; global pooling or deeper downsampling during spatial encoding discards positional precision that the 64-unit LSTM needs. AripinModified (3.85M ConvNeXt-style, global pool) regresses to 25.30% random phrases, supporting this finding.

Frame differences add complementary motion evidence without new preprocessing. Petridis et al. report raw+difference stream fusion improves speaker-independent performance on small datasets. V2's zero-initialized gate lets the model learn motion use, because initial gate output is ≈0.12 — raw stream dominates at start.

Explicit padding masking removes a source of distribution shift. ROI preprocessing center-crops long clips and black-pads short clips; prior models treat padded frames as real content. pack_padded_sequence, last-valid endpoint selection, and masked attention ensure the classifier sees only true mouth frames.
