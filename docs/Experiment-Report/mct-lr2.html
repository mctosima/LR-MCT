MCT-LR2 design

Residual image encoder + motion-aware landmark encoder + bidirectional cross-attention fusion. The image stream uses a 3-stage ResNet-style backbone (32→64→128→256) with per-frame 2-layer bidirectional LSTM. The landmark stream computes inter-frame coordinate deltas, concatenates them with raw positions, and passes them through a 3-layer bidirectional GRU. Both streams project to 256-d before entering two independent cross-attention blocks that let each modality attend to the other's full temporal sequence.

Modality dropout (10% per stream, training only) prevents the classifier from over-relying on one modality. Gradient reversal + speaker classifier pushes the fused representation to discard speaker-identifying features, targeting the cross-speaker generalisation problem that collapsed MCT-LR (11.06% grouped words) and limits all baselines on IndoLR's 8-speaker setup.

Reference: LipFormer (Xue et al., IEEE TCSVT 2023) for visual-landmark cross-attention; Landmark-Guided Cross-Speaker Lip Reading (Wu et al., LREC-COLING 2024) for speaker-invariant representation learning.

Both streams project to 256-d before cross-attention, so the fusion blocks operate in a shared embedding space. Modality dropout zeroes one projected sequence per sample with p=0.1 each, never both. GRL scale follows a sigmoid ramp: grl = 2/(1+exp(−10·progress)) − 1. Speaker loss weight is 0.1 relative to class loss.

Image backbone

  • Conv stem: 1→32, SiLU, MaxPool
  • 3 residual stages: 32→64, 64→128, 128→256
  • Each stage: 2 blocks, first with stride-2 shortcut
  • Per-block: 2× Conv3×3 (bias-free) + BatchNorm + SiLU
  • AdaptiveAvgPool2d(1) → 256-d per frame
  • BiLSTM-2(192) → Linear+LN 384→256

Landmark backbone

  • Compute frame differences: [0, x₁−x₀, x₂−x₁, …]
  • Concat raw coords + deltas → 160-d
  • LayerNorm → BiGRU-3(192) → Linear+LN 384→256
  • Motion evidence without new preprocessing
  • 3-layer GRU chosen over LSTM for faster convergence on short sequences

Regularisation

  • Modality dropout: 10% image, 10% landmark (never both)
  • Label smoothing 0.1
  • Dropout 0.3 (LSTM/GRU), 0.4 (head), 0.2 (speaker)
  • Augmentation: contrast/brightness/noise on ROI, scale/translate/noise on landmarks
  • Zero-padding preservation: padded frames stay black through augmentation
  • Gradient clipping at 5.0

Training configuration

  • Optimizer: AdamW, lr=3e-4, wd=1e-4
  • Batch size 4, grad accumulation 1
  • Max 150 epochs, early-stop patience 20
  • Best checkpoint by validation macro-F1
  • Mixed precision (AMP) on CUDA
  • No learning-rate scheduler
  • GRL: sigmoid ramp from 0→1 over optimizer steps
  • Loss = CrossEntropy(label_smoothing=0.1) + 0.1 × SpeakerCE

Design reading

Cross-attention alone is insufficient for 8-speaker cross-validation with 5,800 samples. MCT-LR2 raises grouped-word accuracy from MCT-LR's catastrophic 11.06% to 43.87%, but still trails Aripin's image-only 50.93%. High per-fold LOSO variance (9.7%–59.6%) confirms the model overfits speaker-specific lip patterns despite adversarial training. Grouped phrases regressed to 28.81% with early stopping at epoch 9.

Next steps: pretrained backbone (MobileNet/ResNet), stronger modality dropout (>0.3), larger batch size with more aggressive augmentation, or multi-seed ensemble across LOSO folds. The 7.56M parameter budget and architecture are sound; the 5,800-sample dataset is the bottleneck.
